# Security Policy

This repository is a **showcase**: documentation, screenshots and one example policy file. It contains no executable code. The AI Audit Center source code is kept in a private repository.

## Reporting a problem

If you notice sensitive data in this repository (for example a host name, user name, path or token that should have been redacted in a screenshot), please use **GitHub private vulnerability reporting** on this repository ("Security" tab → "Report a vulnerability"). Please don't open a public issue.

## About the screenshots

The screenshots come from a real run on the author's own Windows machine. Host name, user name, account IDs (SIDs), MAC and private IP addresses, and third-party application names were replaced before the images were taken. Security findings in them describe that one machine at that moment and are shown only to illustrate the tool.

## Scope and limits of the project

- Student learning project, tested on a single personal Windows machine.
- Not a commercial product, not deployed in any organisation, not independently audited or penetration-tested.
- Not an antivirus, EDR or forensic product.
- The analysis is rule-based. The "AI" in the name refers to the analysis layer, not to a machine-learning model.
